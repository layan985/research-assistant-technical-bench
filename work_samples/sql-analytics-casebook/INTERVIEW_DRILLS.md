# SQL interview drills

For every query, answer:
1. What is the grain of each CTE?
2. Can the join multiply rows?
3. What exactly is the denominator?
4. How are NULLs handled?
5. Is the window frame correct?
6. Which index would help?
7. How would this change in PostgreSQL/BigQuery/Snowflake?
8. How would you reconcile the result to a trusted total?
