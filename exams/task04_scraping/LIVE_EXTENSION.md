# Live extension — real public-sector corpus

Complete this only after passing the deterministic local benchmark.

Choose one public government/document portal whose robots.txt and terms permit automated access. Freeze the target before starting: domain, collection, fields, date range, rate limit, and stopping rule. Aim for 10,000 document records, but stop rather than bypassing access controls or escalating request rates.

Your live extension should preserve the same output contract as the benchmark and add: `SOURCE_POLICY.md` documenting robots/terms checks, request rate, user agent, retrieval date, failures, and any inaccessible documents. Store URLs and metadata; do not republish copyrighted full-text PDFs unless their license permits it.

The point of the live extension is to demonstrate production judgment. The local benchmark remains the comparable timed score.
