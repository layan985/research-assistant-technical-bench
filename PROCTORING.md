# Self-proctoring protocol

For a credible public attempt:

- create a fresh branch before starting;
- run `start_exam.py` and commit the generated `ATTEMPT.json` immediately;
- screen-record only if you personally want stronger evidence; it is not required;
- make no commits to raw inputs;
- submit at 90 minutes even if incomplete, then continue only in a separately marked `overtime` commit;
- run the grader after submission;
- write a five-line retrospective before opening `reference/`;
- never retroactively overwrite a weak first attempt. Improvement is part of the signal.
